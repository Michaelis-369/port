Deployable HTML file — no server, no install
The Constraint

No server, no install, no internet dependency — and still real access control.

The deployment environment couldn't assume a server, a package manager, or a reliable connection, but the tool still needed role separation, session security, and safe transaction handling at scale — over 10,000 items.

The Decision

Build the whole system as one self-contained file.

Rather than a client-server split, the entire application — UI, transaction engine, RBAC, and session logic — was built to run from a single HTML file with zero external dependencies, deployable by copying one file.

The Build

Full transaction engine with guardrails against bad data.

  • Role-based access control — Supervisor and Operator roles
  • 5-minute session timeout
  • Full transaction engine with negative-inventory and duplicate-entry prevention
  • Real-time search across 10,000+ items
  • Single deployable HTML file, zero external runtime dependency
