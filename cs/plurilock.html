The Constraint

Manual content production didn't scale, and neither did its cost.

Producing a single piece of AI-related content took roughly 5 hours of manual work and cost about $185 once labor was accounted for — a pace that couldn't support the cadence the marketing team actually needed.

The Decision

Build the whole pipeline, not a prompt template.

Rather than hand editors a single-shot prompt, the platform was architected around persona-based prompt chaining — multiple structured passes through the Claude API, each shaping tone, structure, and accuracy — with sanitized output going straight to WordPress. That end-to-end ownership is what took the process from hours to minutes.

The Build

Term 1 — a complete platform, solo.

  • Python/Flask backend with Claude API integration and persona-based prompt chaining architecture
  • Google OAuth 2.0 with email-allowlist role-based access control
  • Real-time API cost tracking dashboard
  • HTML sanitization pipeline for direct WordPress publishing — zero manual reformatting

OAuth/RBAC gate → Flask backend → Claude API → sanitize → publish, with compute split across EC2 / Lightsail

Term 2 — multi-agent infrastructure

  • AWS EC2 for compute-heavy inference and Lightsail for web-facing services, separated into service tiers for cost and availability
  • Real-time observability platform tracking agent performance, latency, cost, and reliability
  • RFP automation pipeline: ingest → requirement extraction → capability matching → draft generation
  • Evaluation frameworks measuring output quality per workflow category
