Infrastructure · Local Inference

Local LLM Inference System
& RAG Pipeline

CPU-based local LLaMA inference with privacy-aware query routing, backed by a full retrieval-augmented generation stack for document-grounded answers.

60%+
Reduction in cloud API calls via local routing
The Constraint

Not every query should leave the machine.

Sending every query to a cloud LLM is expensive and, for privacy-sensitive prompts, undesirable regardless of cost. The system needed a way to keep sensitive or low-complexity queries entirely local while still using the cloud where it genuinely adds capability.

The Decision

Route by privacy classification and compute constraint, not by default.

Rather than route everything to the cloud or everything locally, an intelligent router classifies each query by privacy sensitivity and compute requirement before dispatching it — local CPU-based LLaMA inference for what it can handle, cloud only when necessary.

Document → chunk → embed → vector store → query → routing decision → local or cloud inference

The Build

A full RAG stack, tuned against measured retrieval precision.

  • PDF parsing, chunking, and embedding generation feeding a vector store index (LangChain / LlamaIndex)
  • CPU-based local LLaMA inference with intelligent query routing by privacy classification and compute constraint
  • Evaluation harness benchmarking retrieval precision across prompt variations
  • Chunking and retrieval parameters iterated based on measured evaluation scores, not intuition

Precision benchmark used to select chunk size and overlap parameters

The Result

Most queries never leave the machine.

Intelligent routing cut cloud API calls by more than 60%, with retrieval precision measured and iterated rather than assumed — a system tuned on evidence at every stage.
