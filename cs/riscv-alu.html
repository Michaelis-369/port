RISC-V ALU

A gate-level ALU implementation in Verilog, verified with the same rigor as a production software system — self-checking testbench, waveform verification, and synthesis analysis.

github.com/irankunda5/RISC-V-ALU
7
Operations, full functional coverage
The Constraint

RTL correctness has to be proven, not assumed.

An ALU is the core of any datapath — a silent off-by-one in a shift or a flag calculation propagates everywhere downstream. The design needed proof of correctness across every operation and edge case, not just a handful of manual test vectors.

The Decision

Build the testbench to check itself.

Rather than eyeball waveform output, the testbench was written to be self-checking — generating randomized and edge-case vectors, computing expected results independently, and flagging any mismatch automatically.

Inputs A/B and opcode select feed the ALU core; result and flags exit as a single bus

The Build

Simulated, waveform-verified, and synthesized to gates.

  • Verilog RTL implementing ADD, SUB, AND, OR, XOR, SLT, and shift operations
  • Self-checking testbench with randomized and edge-case vectors, full functional coverage
  • Simulated in Icarus Verilog, waveform-verified in GTKWave
  • Synthesized to a gate-level netlist in Yosys with critical path and area analysis
// alu.v — opcode-selected ALU core (excerpt) module alu ( input [31:0] a, b, input [3:0] opcode, output reg [31:0] result, output reg zero, overflow ); always @(*) begin case (opcode) 4'b0000: result = a + b; // ADD 4'b0001: result = a - b; // SUB 4'b0010: result = a & b; // AND 4'b0011: result = a | b; // OR 4'b0100: result = a ^ b; // XOR 4'b0101: result = ($signed(a) < $signed(b)) ? 1 : 0; // SLT 4'b0110: result = a << b[4:0]; // SLL 4'b0111: result = a >> b[4:0]; // SRL default: result = 32'b0; endcase zero = (result == 32'b0); end endmodule
Testbench functional coverage
  • ✓ ADD — random + overflow edge
  • ✓ SUB — random + underflow edge
  • ✓ AND / OR / XOR — bitwise sweep
  • ✓ SLT — signed boundary cases
  • ✓ SLL / SRL — shift amount 0–31
  • ✓ Zero flag — all-zero result
The Result

Full functional coverage, gate-level critical path identified.

Every operation passes the self-checking testbench across randomized and edge-case vectors, with behavior confirmed in GTKWave and a synthesized netlist analyzed for critical path and area in Yosys.
