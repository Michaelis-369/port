Self-Directed ML Curriculum

An eight-week structured curriculum built to understand machine learning from first principles before reaching for a framework.

8 wks
Structured, depth-first curriculum
The Constraint

Frameworks hide the math that makes them work.

Jumping straight to TensorFlow or scikit-learn teaches API surface, not mechanism. The goal was to actually understand gradient descent, distance metrics, and backpropagation well enough to implement them, not just call them.

The Decision

Implement from scratch first. Frameworks second.

Every algorithm was implemented in raw NumPy before ever touching a framework equivalent — forcing an honest confrontation with the underlying math rather than trusting a library's abstraction.

The Build

From linear regression to CNNs, in eight weeks.

  • Implemented from scratch in NumPy: linear regression, logistic regression, K-means, PCA, and neural networks
  • Extended into TensorFlow/Keras for CNNs, RNNs, and model deployment

Framework fluency backed by first-principles understanding.

The curriculum produced working from-scratch implementations of every core algorithm and a framework-based extension into deep learning — the same depth-first approach applied throughout the rest of this portfolio.
